# Todolist

A single-user task list exposed as a JSON REST API: create Tasks, mark them completed, and remove them.

## Language

**Task**:
A single piece of work to be done, tracked in the list.
_Avoid_: Todo, item, note, entry

**Completed**:
The state of a Task whose work is done. A Task is either completed or not; there is no partial state.
_Avoid_: Done, finished, closed, checked
